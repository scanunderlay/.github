# Security policy

Scan Underlay takes the security of its websites, web tools, and code seriously. If you find a security problem, tell us privately so we can fix it before anyone misuses it.

## Scope

This policy covers:

- Our websites and web tools, such as [scanunderlay.com](https://www.scanunderlay.com).
- The code in every repository of the [`scanunderlay`](https://github.com/scanunderlay) GitHub organization.

It does not cover:

- Denial of service, spam, or load testing.
- Social engineering or phishing of our employees, customers, or partners.
- Physical attacks on our offices or production sites.
- Services we use but do not run, such as GitHub or our hosting providers. Report those to the provider.

## Report a vulnerability

Never report a security problem in a public issue, discussion, or pull request.

Email [security@scanunderlay.com](mailto:security@scanunderlay.com). Include as much of the following as you can:

- The type of problem, such as cross-site scripting, broken access control, or exposed credentials.
- The affected website, page, or repository, with the URL, branch, or commit.
- Step-by-step instructions to reproduce it, and any special setup it needs.
- A proof of concept, if you have one.
- What an attacker could do with it.

## What happens next

1. We confirm we received your report as soon as we can.
2. We investigate, and tell you whether we can reproduce the problem.
3. We fix it, and tell you when the fix is live.
4. We credit you when we announce the fix, unless you ask us not to.

Please give us a reasonable time to fix the problem before you share it with anyone else.

## Supported versions

Our websites and web tools run one live version. We fix security problems in that version only.

## Safe harbor

We will not take legal action against anyone who, in good faith, follows this policy: reports privately, avoids harming people's privacy and data, avoids disrupting our services, and accesses only what is needed to show the problem.
